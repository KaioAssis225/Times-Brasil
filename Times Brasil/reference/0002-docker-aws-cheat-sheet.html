Docker + AWS Deployment Cheat Sheet

1. Comandos para autenticar e enviar imagem FastAPI ao Amazon ECR:

# 1. Login no ECR via AWS CLI
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com

# 2. Build da imagem Docker da FastAPI
docker build -t meu-fastapi-backend .

# 3. Tag para a AWS
docker tag meu-fastapi-backend:latest ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com/meu-fastapi-backend:latest

# 4. Push da imagem
docker push ACCOUNT_ID.dkr.ecr.us-east-1.amazonaws.com/meu-fastapi-backend:latest

2. String de Conexão com o PostgreSQL no RDS:

DATABASE_URL=postgresql://usuario:senha@meu-postgres.c123456789.us-east-1.rds.amazonaws.com:5432/nome_do_banco
