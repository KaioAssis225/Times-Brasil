AWS Hosting & Storage Cheat Sheet

Serviço Tipo Ideal para Nível de Gerenciamento
Amazon S3 Storage de Objetos Arquivos estáticos, uploads, backups, sites frontend (HTML/React). Sem servidor (Serverless)
Amazon CloudFront CDN / Distribuição Acelerar entrega de conteúdo, HTTPS gratuito, segurança para S3. Gerenciado pela AWS
Amazon EC2 Computação / Servidor Virtual APIs, backends completos, controle total sobre SO e pacotes. Você gerencia a máquina (Linux/Windows)
AWS App Runner Container Hosting Deploy simplificado de APIs Node/Python/Docker sem configurar EC2. Totalmente Gerenciado
Amazon RDS Banco de Dados Relacional MySQL, PostgreSQL com backup automático e réplicas. Gerenciado
