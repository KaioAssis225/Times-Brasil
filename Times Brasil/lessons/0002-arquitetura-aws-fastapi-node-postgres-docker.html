Como hospedar sua Stack na AWS

Frontend TypeScript + Backend FastAPI (Docker) + PostgreSQL na nuvem.

💡 Visão Geral da sua Arquitetura:
Em vez de colocar tudo em uma única máquina gigante, na AWS separamos a aplicação em 3 partes especializadas.

1. O Desenho da Arquitetura na AWS

1

Frontend TypeScript / Node TypeScript / React

Serviço AWS: Amazon S3 + CloudFront (CDN)
Você faz o build estático (npm run build) e envia a pasta de build pro S3. O CloudFront entrega o site com SSL (HTTPS) grátis e velocidade global.

2

Backend FastAPI (Python) em Contêiner FastAPI Docker

Serviço AWS: Amazon ECR + AWS App Runner (ou EC2)
Você gera a imagem Docker da sua API FastAPI, publica no registry privado (Amazon ECR) e roda no AWS App Runner (que gerencia HTTPS, porta 8000 e auto-scaling automaticamente).

3

Banco de Dados PostgreSQL PostgreSQL

Serviço AWS: Amazon RDS para PostgreSQL
Instância de banco de dados relacional gerenciado. A API FastAPI se conecta usando a variável de ambiente DATABASE_URL com segurança dentro da nuvem.

🧠 Teste de Fixação

Onde a sua imagem Docker do FastAPI deve ser armazenada antes de ser executada na AWS?

A) Diretamente na pasta de arquivos do Amazon S3.
B) No Amazon ECR (Elastic Container Registry), o repositório oficial de imagens Docker da AWS.
C) Dentro do banco de dados PostgreSQL.
