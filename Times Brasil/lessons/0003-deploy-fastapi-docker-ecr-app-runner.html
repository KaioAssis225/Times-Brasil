Deploy do FastAPI com Docker no Amazon ECR & App Runner

Passo a passo para empacotar sua API Python em contêiner e publicar em produção na AWS.

1 Criar o `Dockerfile` da sua API FastAPI

No diretório do seu backend FastAPI, crie um arquivo chamado Dockerfile:

FROM python:3.11-slim

WORKDIR /app

# Instalar dependências
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copiar código da aplicação
COPY . .

# Expor a porta que o Uvicorn usará
EXPOSE 8000

# Executar a API com Uvicorn
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
2 Criar o Repositório no Amazon ECR

O Amazon ECR guarda suas imagens Docker com segurança. Você pode criar pelo painel da AWS ou via terminal:

# Criar o repositório ECR chamado 'fastapi-backend'
aws ecr create-repository --repository-name fastapi-backend --region us-east-1
3 Fazer Build, Tag e Push da imagem Docker

Execute no seu terminal (substituindo SUA_CONTA_ID pelo número da sua conta AWS):

# 1. Autenticar o Docker no Amazon ECR
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin SUA_CONTA_ID.dkr.ecr.us-east-1.amazonaws.com

# 2. Fazer o build da imagem local
docker build -t fastapi-backend .

# 3. Marcar (Tag) para a AWS
docker tag fastapi-backend:latest SUA_CONTA_ID.dkr.ecr.us-east-1.amazonaws.com/fastapi-backend:latest

# 4. Enviar (Push) para a AWS
docker push SUA_CONTA_ID.dkr.ecr.us-east-1.amazonaws.com/fastapi-backend:latest
4 Criar o Serviço no AWS App Runner

No console da AWS, pesquise por AWS App Runner e clique em Create Service:

  • Repository type: Container Registry
  • Provider: Amazon ECR
  • Image: Selecione fastapi-backend:latest
  • Port: 8000
  • Environment Variables: Adicione DATABASE_URL (conectar ao PostgreSQL)

✅ O App Runner criará uma URL HTTPS automática (ex: https://abc123xyz.us-east-1.awsapprunner.com) para sua API!
