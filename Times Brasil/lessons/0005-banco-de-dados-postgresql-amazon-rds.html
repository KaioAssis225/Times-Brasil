Lição 05 • Database Management

Banco de Dados PostgreSQL no Amazon RDS

Como criar uma instância gerenciada de PostgreSQL e conectar com sua API FastAPI.

1 Por que usar Amazon RDS em vez de instalar Postgres na máquina?

O Amazon RDS (Relational Database Service) cuida das tarefas difíceis de banco de dados por você:

  • ✅ Backups Automáticos Diários: Se você corromper um arquivo ou deletar dados por engano, pode restaurar em segundos.
  • ✅ Updates e Patches de Segurança: A AWS atualiza o PostgreSQL sem derrubar a aplicação.
  • ✅ Failover / Réplicas: Se o servidor principal tiver problemas, uma réplica assume sem queda.
2 Criando o Banco PostgreSQL no Console AWS

No painel do Amazon RDS, clique em Create Database e escolha as opções:

  • Engine type: PostgreSQL
  • Templates: Free tier (elegível ao nível gratuito)
  • DB instance identifier: meu-postgres-prod
  • Master username: postgres (ou usuário de sua escolha)
  • Master password: Defina uma senha forte
  • Connectivity: Marque a opção de associar um Security Group que permita tráfego na porta 5432
3 Obtendo o Endpoint e Conectando com a FastAPI

Após a criação, o RDS gerará um Endpoint (endereço de acesso público ou interno):

# Endereço do Endpoint no RDS
meu-postgres-prod.c123456789.us-east-1.rds.amazonaws.com

# Formato da variável de ambiente DATABASE_URL que você coloca no App Runner / Docker:
DATABASE_URL=postgresql://postgres:SuaSenhaSegura@meu-postgres-prod.c123456789.us-east-1.rds.amazonaws.com:5432/meudb
4 Testando a Conexão em Python (FastAPI / SQLAlchemy)

Exemplo de código em Python usando SQLAlchemy / SQLModel para ler a URL de conexão com segurança:

import os
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

# Lê a URL de conexão definida nas variáveis de ambiente da AWS
DATABASE_URL = os.getenv("DATABASE_URL")

engine = create_engine(DATABASE_URL)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

🧠 Teste de Fixação

Onde é o lugar correto e seguro para guardar a senha e a URL do seu banco de dados PostgreSQL na AWS?

A) Escrita diretamente no código da aplicação (hardcoded no main.py).
B) Em Variáveis de Ambiente (Environment Variables) no AWS App Runner ou AWS Secrets Manager.
C) Salva na pasta pública do S3.
