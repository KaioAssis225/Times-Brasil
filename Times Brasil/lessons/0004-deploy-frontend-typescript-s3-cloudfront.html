Hospedagem do Frontend TypeScript / Node com S3 & CloudFront

Como publicar seu site React/Vite/TypeScript com alta velocidade global, SSL grátis e custos centavos.

1 Gerar os Arquivos Estáticos (`npm run build`)

No seu projeto TypeScript/Node (React, Vite, Next.js estático), rode o comando de compilação:

# Executa o build de produção (gera a pasta dist/ ou build/)
npm run build

Os arquivos gerados em dist/ (como index.html, JS minificado e CSS) serão o conteúdo do seu site.

2 Criar o Bucket S3 e Fazer o Sincronismo

Crie um bucket no Amazon S3 para armazenar os arquivos estáticos:

# 1. Criar o Bucket S3 (o nome deve ser único no mundo todo)
aws s3 mb s3://meu-frontend-typescript-2026 --region us-east-1

# 2. Sincronizar a pasta 'dist' local diretamente para o S3
aws s3 sync dist/ s3://meu-frontend-typescript-2026 --delete
3 Criar a Distribuição no Amazon CloudFront (CDN)

O CloudFront distribui o seu site em servidores ao redor do mundo, oferece HTTPS (SSL) grátis e oculta o S3 por segurança:

  • Origin Domain: Escolha seu bucket S3 (meu-frontend-typescript-2026.s3.amazonaws.com).
  • Origin Access: Selecione Origin Access Control (OAC) — permite que apenas o CloudFront leia seu S3.
  • Viewer Protocol Policy: Redirect HTTP to HTTPS.
  • Default Root Object: index.html.
  • Custom Error Responses (Para SPAs como React/Vite): Crie uma regra redirecionando erros 403/404 para /index.html com HTTP Status 200.
4 Habilitar CORS na sua API FastAPI

Para o seu frontend TypeScript conseguir fazer chamadas fetch() / axios para o seu backend FastAPI sem erros de bloqueio do navegador:

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

# URL gerada pelo CloudFront (ou seu domínio próprio)
origins = [
    "https://d123456789.cloudfront.net",
    "https://meusite.com",
    "http://localhost:5173"
]

app.add_middleware(
    CORSMiddleware,
    allow_origins=origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

Se o seu usuário recarregar a página em https://seusite.com/dashboard em um app React/SPA e der erro 404, qual configuração no CloudFront resolve o problema?

B) Configurar uma página de erro customizada (Custom Error Response) apontando 404 -> /index.html com resposta 200.
