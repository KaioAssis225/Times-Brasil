O Mapa de Serviços da AWS

Entenda para onde vai cada peça do seu sistema (Sites, APIs e Bancos de Dados) antes de subir o primeiro arquivo.

🎯 Regra de Ouro dos Arquitetos de Nuvem: Não use um servidor inteiro (EC2) se você só precisa servir um site estático ou React/Vue/HTML. Escolha o serviço certo para pagar menos e ter zero manutenção de servidor.

1. As 3 Categorias Fundamentais

🌐

Amazon S3 + CloudFront

Perfeito para Sites Estáticos, React/Vite/Next exportado, imagens e uploads de usuários. Barato, ultra-rápido e não cai nunca.

Hospedagem Estática
⚙️

Amazon EC2 / App Runner

Para Backends e APIs (Node.js, Python, Java, PHP, Docker). Processa requisições, roda código no servidor e executa regras de negócio.

Processamento / Server
🗄️

Amazon RDS / DynamoDB

Para Bancos de Dados (PostgreSQL, MySQL). Armazena dados estruturados com backups automáticos e segurança gerenciada.

Armazenamento de Dados

🧠 Teste de Fixação Rápido

Você criou um portfólio pessoal construído em React (Vite). Ele não possui um backend próprio, apenas exibe informações. Qual é a melhor escolha na AWS?

A) Criar uma instância EC2 (Servidor Linux) e rodar Nginx.
B) Hospedar no Amazon S3 com distribuição via CloudFront (CDN).
C) Instalar em um banco de dados Amazon RDS.
